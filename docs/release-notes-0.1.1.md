# Workbench 0.1.1

这一版重新整理了 Workbench 面向普通用户的入口和云端分享体验。安装后可以直接新建、打开、编辑和导出文档；不使用在线分享时，不需要注册账号，也不需要配置任何存储信息。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.1-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.1-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次改进

- **本地功能零配置**：首次安装默认不创建云端连接，打开、编辑、阅读和导出文档可以立即使用。
- **安装入口更清楚**：用户说明只保留下载、安装和使用步骤，源码开发内容移到独立贡献指南。
- **云端分享按需开启**：设置页先说明“不配置也能用”，只有主动选择阿里云存储或单位提供的连接后才显示表单。
- **高级参数不再干扰普通路径**：自定义服务地址、临时授权和额外身份参数默认折叠。
- **界面用语更易理解**：用“云端分享”“浏览器快捷菜单”“存储空间名称”等用户能识别的表达替代内部实现名称。
- **手机布局修复**：解决设置页在窄屏或窗口宽度变化后出现的拉伸、左侧裁切和表单样式丢失。

## 主要功能

- 新建文档，或从电脑、公开网址、GitHub 文件页和 Gist 打开 Markdown。
- 在编辑、左右分屏和阅读模式之间切换，显示表格、待办事项、代码、公式和流程图。
- 自动保存当前浏览器中的恢复草稿。
- 导出为 Markdown、独立网页或可编辑的 Word 文档，也可通过浏览器保存为 PDF。
- 按需连接自己的存储，上传文件或生成在线分享链接。
- 调整功能顺序、隐藏不用的项目，并添加常用网页工具。

## 数据与隐私

- 本地文件默认不会上传。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 默认只申请保存设置和下载文件所需的权限；读取某个网址时，才会申请访问该网站。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 安装包仍需完成商店打包、签名和真机验证。
- 上传和在线分享属于可选功能，需要用户已有自己的阿里云存储，或获得单位、服务提供者给出的连接信息。
- 旧版能力尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
