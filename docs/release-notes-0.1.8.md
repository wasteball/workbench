# Workbench 0.1.8

这一版修复表格编辑时的页面抖动，并让改动审阅的快速切换始终可用。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是 Chrome 商店上线前的公开预览版：

1. 下载 `workbench-browser-extension-0.1.8-chrome.zip`。
2. 右键 ZIP 文件并选择“全部解压”。
3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。Chrome 商店版上线后，将改为在商店中直接安装和自动更新。

## 本次修复

- 编辑表格单元格时，只更新正在修改的表格，不再重新绘制整篇文档，页面不会因此明显抖动。
- 打开“改动审阅”后，右侧的上一处、当前序号和下一处快速切换会继续显示。
- 点击快速切换的当前序号，可以重新定位到当前改动。
- 表格后方的标题、段落和图表会保持原有状态，不会因一次表格修改被销毁后重建。

## 验证情况

- 真实 Chrome 中编辑表格后，仅替换 1 个表格内容块，其他正文节点保持不变。
- 打开改动审阅后，快速切换仍然显示；重复选择当前改动可以再次定位。
- 桌面和 390px 移动视图的表格审阅、单元格修改、增删行和整表撤回均通过验收。
- 18 个测试文件共 51 项单元测试全部通过；STS 测试、ESLint、TypeScript、发布内容扫描和 Chrome 正式构建均通过。
- 浏览器控制台和页面运行错误均为 0。

## 数据与权限

- 本次更新没有新增浏览器权限，也没有改变本地文件、云端分享或用户偏好的处理方式。
- 本地文件默认不会上传；只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- 当前仍需手动加载预览版，正式面向普通用户的 Chrome 商店版本尚未上线。
- 使用兼容式文件选择时，Chrome 重启后可能需要重新选择原文件以恢复读取权限；浏览器中的草稿和文件记录不会因此删除。
- 本地相对图片解析、提示框完整样式、脚注、图片灯箱和外部文件变化检测尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
- 阿里云 OSS 和单位提供的上传连接属于可选功能，仍需用户提供自己的有效配置。
