# Workbench 0.1.2

这一版把 Markdown 工作区中缺失的常用能力补了回来。安装后默认进入阅读模式，可以直接打开一个文件，也可以选择文件夹、网址或把文件拖进工作区。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.2-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.2-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次改进

- **打开更直接**：工具栏默认提供“打开文件”，下拉菜单中可选择打开文件夹或网址，也可以直接拖入文件或文件夹。
- **阅读、编辑和源码更清楚**：三种模式使用固定切换控件；手机宽度下编辑模式会完整显示编辑器。
- **流程图恢复完整交互**：Mermaid 图表可在图表与源码之间切换，支持拖动、缩放、适应画布、全屏和复制图片。
- **查找替换覆盖整个工作区**：阅读、编辑和源码模式共用同一个查找入口，支持结果计数、前后定位、大小写匹配、单处替换和全部替换。
- **改动可以逐项审阅**：显示未保存改动数量和修改前后内容，可定位上一处或下一处，也可撤回单处或全部改动。
- **长文档导航恢复**：根据当前位置显示回到顶部或底部按钮，图表加载导致文档高度变化时仍能准确到达目标位置。

## 数据与权限

- 本地文件默认不会上传，打开、阅读、编辑、查找和导出都在本机完成。
- 本次更新没有新增浏览器权限，也没有改变云端分享的默认关闭状态。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 只能生成扩展资源，仍需完成 macOS/Xcode 包装、签名和真机验证，因此本次没有 Safari 安装包。
- 文件夹内文档当前仍按平面列表显示，尚未提供目录树；本地相对图片解析仍待迁移。
- 富文本块编辑、提示框、脚注、图片灯箱、阅读偏好和外部文件变化检测尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
