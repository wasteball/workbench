# Workbench 0.1.11

这一版让文件上传、下载、分享和存储配置更适合普通用户使用，并增加偏好与文件库备份。文件夹上传也做了性能优化，已用 108 个文件完成真实 Chrome 验证。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

首次安装：

1. 下载 `workbench-browser-extension-0.1.11-chrome.zip`。
2. 右键 ZIP 文件并选择“全部解压”。
3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

## 从旧预览版升级

不要先卸载旧版。卸载扩展会让 Chrome 清除当前插件的偏好、草稿和文件库记录。

1. 先在“设置 → 权限与隐私”中选择“备份偏好与文件库”。
2. 下载并解压新版，把新版文件覆盖到原来加载 Workbench 的文件夹。
3. 打开 `chrome://extensions`，在 Workbench 卡片上点击“重新加载”。

使用原文件夹直接更新时，偏好、草稿和文件库记录会保留。若已经卸载，只能从之前导出的备份恢复偏好、分类和文件库记录；对象存储中的远端文件不会因卸载插件而删除。

## 本次更新

- **备份与恢复**：可以备份主题、阅读宽度等偏好，以及文件库分类和上传记录；AccessKey、API 用户标识和请求头密钥不会写入备份。
- **两种存储方式**：云端配置改为“API 方式 / 阿里云 OSS”单选切换，每种方式只维护一处配置。
- **上传更快**：并发文件共用连接初始化，阿里云普通上传不再预先读取文件列表；批量上传减少剪贴板和界面刷新操作。
- **下载修复**：上传后的文件可以直接下载，中文名称和扩展名保持不变；对象地址禁止跨域读取时会在新标签打开。
- **分享更直接**：点击“分享”会复制可直接粘贴到聊天工具中的文字，默认是文件名、换行、链接；格式仍可在设置中修改。
- **文件库更轻**：分类改为行内下拉框，批量移动使用紧凑下拉框；分类和类型筛选保持单行滚动。
- **打开入口**：上传完成区和文件库都提供明确的打开、下载和分享操作。

## 数据与权限

- 本次更新没有新增浏览器权限。
- 同一插件直接更新会保留本地数据；卸载会清除 Chrome 为该插件保存的偏好、草稿和文件库记录。
- 备份包含文件库中的分享链接。链接可能带有限时访问参数，请妥善保管备份文件。
- 恢复备份后，需要重新填写 AccessKey、API 用户标识或私密请求头。
- 本地文件默认不会上传，只有主动上传或在线分享时才会连接用户选择的存储服务。

## 已知限制

- 当前仍需手动加载预览版，正式面向普通用户的 Chrome 商店版本尚未上线。
- 上传和私有文件下载依赖用户自己的 API 服务或阿里云 OSS；服务端仍需正确配置访问权限和 CORS。
- 文件库是当前浏览器的上传记录，不是 OSS Bucket 的完整文件浏览器。
- 备份不能恢复未导出的文档草稿，也不能恢复已经被 Chrome 在卸载时删除且事先没有备份的数据。
- 批量下载会由 Chrome 逐个保存文件，浏览器可能询问是否允许一次下载多个文件。
