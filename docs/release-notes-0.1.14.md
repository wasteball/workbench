# Workbench 0.1.14

这一版让“分享当前文档”真正成为阅读过程中的一步操作：不再跳到文件库，也不会丢失阅读位置。选择分享格式后，Workbench 会生成链接、复制可直接发送的分享内容，并把结果保存到文件库中。

同时，文件上传与链接下载入口重新整理，长文档中的异常引用缩进也已修复。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

首次安装：

1. 下载 `workbench-browser-extension-0.1.14-chrome.zip`。
2. 右键 ZIP 文件并选择“全部解压”。
3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

## 从旧预览版升级

不要先卸载旧版。卸载扩展会让 Chrome 清除当前插件的偏好、草稿和文件库记录。

1. 建议先在“设置 → 权限与隐私”中选择“备份偏好与文件库”。
2. 下载并解压新版，把新版文件覆盖到原来加载 Workbench 的文件夹。
3. 打开 `chrome://extensions`，在 Workbench 卡片上点击“重新加载”。

使用原文件夹直接更新时，主题、阅读宽度、草稿、分类和文件库记录都会保留。

## 本次更新

- **分享不再离开当前文档**：阅读时点击“分享”会在原页面打开选择框，关闭或分享完成后仍停留在原文档、原模式和原阅读位置。
- **选择分享格式后直接复制**：支持 HTML 网页、Word 文档和 Markdown；默认复制“文件名、换行、链接”，可继续使用设置中的其他分享文字格式。
- **分享结果进入文件库**：生成的文件会记录在“文件与分享”中，后续仍可查看、打开、复制链接、下载、分类或移除记录。
- **复制失败也能继续操作**：如果浏览器没有允许自动复制，弹窗会保留生成结果，可手动复制，不需要重新上传。
- **文件入口更清楚**：上传文件、上传文件夹、粘贴上传、上传分类和链接下载重新排版，链接下载继续默认收起。
- **修复异常缩进**：标题、正文、引用框和表格统一对齐阅读列；列表、列表嵌套和嵌套引用才使用层级缩进。导出的 HTML 使用同一规则。

## 数据与权限

- 本次更新没有新增浏览器权限。
- 本次更新没有修改存储配置、文档、草稿、分类或文件库的数据结构。
- 只有用户在分享弹窗中确认后，当前选择的输出文件才会上传到已连接的存储服务。
- 分享格式、分享文字格式、主题和阅读宽度等现有偏好继续保留。
- 同一插件直接更新会保留本地数据；不要为了升级而先卸载旧版。

## 已知限制

- 当前仍需手动加载预览版，正式面向普通用户的 Chrome 商店版本尚未上线。
- 在线分享依赖用户自己的 API 服务或阿里云 OSS；服务端仍需正确配置访问权限和 CORS。
- 文件库是当前浏览器的上传与分享记录，不是 OSS Bucket 的完整文件浏览器。
- 阿里云私密分享链接会按设置的时间失效，失效后需要在已连接原存储的浏览器中重新生成。
- 卸载扩展仍会让 Chrome 清除插件本地数据；必须卸载时，请先备份偏好与文件库。
