# Workbench 0.1.3

这一版把 Markdown 工作区恢复为更适合普通用户的文档编辑器：打开文件后直接看到排版后的正文，需要修改时就在正文中编辑，不必先理解 Markdown 源码。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.3-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.3-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次改进

- **文件和目录都回到左侧**：文件夹保持原有层级，文档目录独立显示，并随阅读位置定位当前标题。
- **直接编辑正文**：点击段落即可修改；选中文字可设置加粗、斜体、删除线、行内代码和链接，复杂内容仍保留高级源码入口。
- **内容块操作恢复**：支持插入、移动、复制和删除内容块，也可以直接修改表格单元格。
- **Mermaid 完整可用**：修复 `flowchart`，所有图表操作统一为图标；悬停可查看 `View source`、`View image`、`Copy image` 等功能名称。
- **查找替换恢复**：选中正文后打开查找会自动带入，支持替换当前项和全部替换。
- **改动审阅恢复旧交互**：正文显示改动位置，清单可逐项定位，并在正文中展开原内容；支持单处撤回、全部撤回和保存接受全部。
- **阅读设置恢复**：可调整正文字体、字号、Reading width 和界面颜色，设置会保存在当前浏览器中。
- **长文档操作恢复**：根据当前位置显示回到顶部或底部按钮。
- **打开大文件夹更快**：先显示文件树，只在点开文档时读取正文，并跳过 `.git`、`node_modules`、`dist` 等目录。

## 数据与权限

- 本地文件默认不会上传，打开、阅读、编辑、查找和导出都在本机完成。
- 本次更新没有新增浏览器权限，也没有改变云端分享的默认关闭状态。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 只能生成扩展资源，仍需完成 macOS/Xcode 包装、签名和真机验证，因此本次没有 Safari 安装包。
- 本地相对图片解析、提示框、脚注、图片灯箱和外部文件变化检测尚未迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
- 阿里云 OSS 和单位提供的上传连接属于可选功能，仍需用户提供自己的有效配置。
