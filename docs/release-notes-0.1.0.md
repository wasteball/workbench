# Workbench 0.1.0

Workbench 的首个公开预览版。它是一个在浏览器里使用的文档工作台，可以打开、编辑、阅读和导出 Markdown 文档；基础功能无需账号或云存储。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.0-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.0-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次提供

- **打开与编辑**：新建文档，或从电脑、公开网址、GitHub 文件页和 Gist 打开 Markdown。
- **阅读与预览**：在编辑、左右分屏和阅读模式之间切换，并显示表格、待办事项、代码、公式和流程图。
- **草稿恢复**：编辑内容自动保存在当前浏览器中，意外关闭后可以继续。
- **多种导出**：导出为 Markdown、独立网页或可编辑的 Word 文档，也可通过浏览器保存为 PDF。
- **可选在线分享**：需要时连接自己的存储，上传文件或把文档生成分享链接；不配置也不影响本地使用。
- **个性化菜单**：调整功能顺序、隐藏不用的项目，并添加常用网页工具。
- **统一设置**：外观、导出、菜单、云端分享和本地数据都在一个设置中心管理。

## 数据与隐私

- 本地文件默认不会上传。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 默认只申请保存设置和下载文件所需的权限；读取某个网址时，才会申请访问该网站。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 安装包仍需完成商店打包、签名和真机验证。
- 上传和在线分享属于可选功能，需要用户已有自己的阿里云存储，或获得单位、服务提供者给出的连接信息。
- 旧版能力尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
