# Workbench 0.1.12

这一版专注于界面升级：Workbench 采用更克制的暖中性色、石墨色主操作和清晰的信息层级，让文档、文件和设置页面更简约、更安静，也更适合长时间使用。现有功能、数据结构和操作流程保持不变。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

首次安装：

1. 下载 `workbench-browser-extension-0.1.12-chrome.zip`。
2. 右键 ZIP 文件并选择“全部解压”。
3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

## 从旧预览版升级

不要先卸载旧版。卸载扩展会让 Chrome 清除当前插件的偏好、草稿和文件库记录。

1. 建议先在“设置 → 权限与隐私”中选择“备份偏好与文件库”。
2. 下载并解压新版，把新版文件覆盖到原来加载 Workbench 的文件夹。
3. 打开 `chrome://extensions`，在 Workbench 卡片上点击“重新加载”。

使用原文件夹直接更新时，主题、阅读宽度、草稿、分类和文件库记录都会保留。

## 本次更新

- **统一视觉系统**：以暖白画布、石墨色文字和低饱和主题色替代原来偏亮的紫蓝界面；主操作、选中状态和辅助状态有了明确分工。
- **更清晰的工作台**：重新调整侧栏、顶栏、页面标题、快捷入口和最近文档的间距、边框、圆角与信息层级。
- **更安静的 Markdown 工作区**：统一文件列表、文档目录、工具栏、阅读正文、表格、图表、查找替换和改动审阅的视觉语言，保留原有操作位置与能力。
- **更轻的文件库与设置**：上传区、分类筛选、文件操作、配置表单和设置导航降低视觉噪声，主次操作更容易区分。
- **插件弹窗同步升级**：新建文档成为明确的首要操作，打开文档、上传文件和最近文档保持紧凑可扫读。
- **亮色与暗色一致**：两种主题共用同一套层级和形状规范，用户选择的主题色仍用于定位、选中和状态提示。
- **移动端重新校对**：针对 390px 宽度调整首页、Markdown 工具栏、文件上传和设置导航，避免遮挡与横向溢出。

- 24 个测试文件共 69 项单元测试全部通过，STS 测试通过。

- 1440px 桌面和 390px 窄屏下页面均无横向溢出，浏览器控制台错误和页面运行错误均为 0。

## 数据与权限

- 本次更新没有新增浏览器权限。
- 本次更新没有修改存储配置、文档、草稿、分类或文件库的数据结构。
- 同一插件直接更新会保留本地数据；不要为了升级而先卸载旧版。
- 本地文件仍默认只在浏览器中处理，只有用户主动上传或在线分享时才会连接所选存储服务。

## 已知限制

- 当前仍需手动加载预览版，正式面向普通用户的 Chrome 商店版本尚未上线。
- 上传和私有文件下载依赖用户自己的 API 服务或阿里云 OSS；服务端仍需正确配置访问权限和 CORS。
- 文件库是当前浏览器的上传记录，不是 OSS Bucket 的完整文件浏览器。
- 卸载扩展仍会让 Chrome 清除插件本地数据；必须卸载时，请先备份偏好与文件库。
