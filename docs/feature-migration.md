# 功能迁移矩阵

更新日期：2026-08-03

本矩阵逐项对应重构前四个 HTML 原型的用户可见功能。它用于防止重构过程中静默删功能，也用于区分“已有代码”“已完成真实验收”和“产品行为已调整”。

状态说明：

- **已完成**：当前扩展已有可用实现和基础验证。
- **已合并**：能力已迁入新的统一入口，旧入口不再保留。
- **部分完成**：主流程可用，但旧版细节尚未全部迁移。
- **待迁移**：仍属于迁移基线，当前扩展尚未实现。
- **行为调整**：已确认不按旧方式保留，并说明替代方案。
- **需外部验收**：代码已实现，但需要真实接口、凭据或平台完成验收。

“已完成”不等于 Chrome 商店发布已通过；发布证据见[发布检查清单](release-checklist.md)。
