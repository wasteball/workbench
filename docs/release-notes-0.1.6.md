# Workbench 0.1.6

这一版让改动审阅和阅读偏好更符合普通用户的使用方式。表格修改不再展示 Markdown 源码，而是直接在表格中标出修改、新增和删除；阅读宽度等偏好会由 Chrome 记住，导出的 HTML 也会保持当前阅读外观。

从本版本开始，Workbench 只维护、验收和发布 Chrome 插件。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是 Chrome 商店上线前的公开预览版：

1. 下载 `workbench-browser-extension-0.1.6-chrome.zip`。
2. 右键 ZIP 文件并选择“全部解压”。
3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。Chrome 商店版上线后，将改为在商店中直接安装和自动更新。

## 本次改进

- **表格改动一眼能看懂**：一张表归为一处改动；修改单元格直接显示“原来”的值，新增行使用绿色，删除行使用红色。
- **不再默认展示表格源码**：普通用户可以在当前表格里完成审阅和整表撤回，不需要理解 Markdown 语法。
- **阅读偏好自动记住**：Chrome 会保存主题、强调色、正文字体、字号、阅读宽度、左侧栏和文件/目录展开状态。
- **HTML 保持当前阅读外观**：导出的 HTML 和在线 HTML 分享会继承当前阅读宽度、字体、字号、主题与强调色；小屏幕仍会自动适配。
- **最近选择继续沿用**：导出格式、在线分享格式和改动标记显示偏好会在下次使用时保留。
- **只维护 Chrome**：自动检查和 GitHub Release 只生成 Chrome 安装包，不再生成 Edge 或 Safari 文件。

## 验证情况

- 表格单元格修改、新增行、删除行、整表撤回均通过真实 Chrome 验收。
- 阅读偏好在刷新后正确恢复；`1040px` 阅读宽度在独立 HTML 中实际渲染为 `1040px`。
- 导出 HTML 在 1440px 桌面和 390px 手机视口均无页面横向溢出。
- 47 项单元测试、STS 测试、ESLint、TypeScript 和 Chrome 正式构建均通过。
- 自动化验收期间浏览器控制台和页面错误均为 0。

## 数据与权限

- 本地文件默认不会上传，打开、阅读、编辑、查找、审阅和导出都在本机完成。
- 阅读偏好保存在当前 Chrome 用户配置中，不会上传到 Workbench 服务。
- 本次更新没有新增浏览器权限，也没有改变云端分享默认关闭的状态。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- 当前仍需手动加载预览版，正式面向普通用户的 Chrome 商店版本尚未上线。
- 使用兼容式文件选择时，Chrome 重启后可能需要重新选择原文件以恢复读取权限；浏览器中的草稿和文件记录不会因此删除。
- 本地相对图片解析、提示框完整样式、脚注、图片灯箱和外部文件变化检测尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
- 阿里云 OSS 和单位提供的上传连接属于可选功能，仍需用户提供自己的有效配置。
