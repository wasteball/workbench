# Workbench 0.1.4

这一版继续完善 Markdown 工作区的正文编辑与导出体验。表格不再平均分列，短的序号列会自动收窄，长说明列会获得更多空间；预览、网页、Word 和 PDF 使用相同的分配规则。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.4-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.4-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次改进

- **表格按内容分配宽度**：序号、编号和 ID 等短列自动收窄，说明类长内容列获得更多空间，不再每列平均分配。
- **表格编辑更完整**：直接点击单元格编辑，并可插入或删除行列、调整列对齐；按 Tab 可以继续编辑下一个单元格。
- **常用内容直接插入**：可以在正文中插入标题、列表、任务、表格、引用、提示、代码、流程图、公式和图片，也可以转换已有内容块的类型。
- **文件更容易找到**：左侧文件区新增名称搜索，打开多个文件或整个文件夹后可快速筛选。
- **查找、替换和审阅更可靠**：选中文字后会自动带入查找框，替换当前项和全部替换会显示结果数量，改动可以查看全部或逐处切换。
- **保存行为更符合预期**：已有文件直接写回原文件；新建文档首次保存时选择位置；取消保存不会继续下载副本。
- **导出体验统一**：默认导出最近一次选择的格式；HTML 会包含 Mermaid 图表，Word 会嵌入渲染后的图表并改善表格与折叠内容，打印/PDF 会在输出前准备图表和分页。
- **操作结果清楚可见**：复制 Mermaid 图片、保存、替换和导出成功或失败后都会显示提示；设置和菜单可点击外部区域或按 Escape 关闭。

## 验证情况

- 使用真实长文档验证了 17 个 Mermaid 图表、9 个折叠区域，以及正文、HTML、Word 和 PDF 中的表格宽度。
- Word 导出中的 24 张表格均未超出正文宽度，17 张图表没有被裁剪。
- Chrome、Edge 和 Safari 资源构建通过；Edge 完成真实扩展交互验收。

## 数据与权限

- 本地文件默认不会上传，打开、阅读、编辑、查找和导出都在本机完成。
- 本次更新没有新增浏览器权限，也没有改变云端分享的默认关闭状态。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 只能生成扩展资源，仍需完成 macOS/Xcode 包装、签名和真机验证，因此本次没有 Safari 安装包。
- 本地相对图片解析、提示框完整样式、脚注、图片灯箱和外部文件变化检测尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
- 阿里云 OSS 和单位提供的上传连接属于可选功能，仍需用户提供自己的有效配置。
