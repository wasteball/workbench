# Workbench 0.1.5

这一版重点解决大文件夹使用、编辑稳定性和 Mermaid/Word 导出问题。打开包含数百个 Markdown 文件的文件夹后，文件列表不会因为重复打开而不断累加；编辑和导出过程中也不会再因图表重复渲染而频繁闪烁。

## 下载与安装

普通用户不需要安装开发工具，也不需要运行任何命令。

当前版本是浏览器商店上线前的公开预览版：

1. Chrome 用户下载 `workbench-browser-extension-0.1.5-chrome.zip`；Edge 用户下载 `workbench-browser-extension-0.1.5-edge.zip`。
2. 右键下载的 ZIP 文件并选择“全部解压”。
3. Chrome 在地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚刚解压的文件夹。

这是预览期的临时安装方式。浏览器商店版上线后，将改为在商店中直接安装和自动更新。Safari 暂未提供普通用户可安装的版本。

## 本次改进

- **文件不会反复累加**：重复打开同一路径文件会复用原记录；重新打开文件夹会替换先前加载且没有改动的文件。
- **可以一键清空文件列表**：文件区新增清空按钮，只清理 Workbench 中的记录，不删除电脑里的原文件；有未保存改动的文档会继续保留。
- **大文件夹更流畅**：文件列表分批显示，不可见项目延后绘制，正文只在点开文件时读取。已使用 320 个 Markdown 文件完成真实 Edge 验收。
- **编辑过程更稳定**：后台排版结果更新时会保留正在编辑的段落、表格单元格和源码编辑框，避免闪烁、失焦或输入内容丢失。
- **Word 导出不再带动页面闪烁**：Mermaid 图表改为缓存并在不可见隔离区域生成，导出过程不再向当前正文反复插入临时图表。
- **Mermaid 显示更可靠**：修复同一图表重复出现、中文中心文字遮挡和边缘裁切；缩小、放大、适应画布、全屏恢复为熟悉的四个图标。
- **Word 代码块更易读**：中文与西文使用合适字体，取消中文字符被强制拉开的效果。
- **改动审阅更清楚**：明确标出保存前内容和当前内容，并增加精确到词的增删高亮。

## 验证情况

- 320 个 Markdown 文件首次打开、重复打开、搜索和清空均通过；重复打开后文件数量不会翻倍。
- 使用完整学习手册验证 17 个 Mermaid 图表、9 个折叠区域、17 张表格，以及 HTML、Word 和 PDF 输出。
- Word 导出约 3.15 MB，独立 HTML 中 17 个图表全部可见，PDF 没有表格或图表裁切。
- Edge 桌面端与 390px 窄屏交互通过，浏览器控制台和页面均无错误。

## 数据与权限

- 本地文件默认不会上传，打开、阅读、编辑、查找和导出都在本机完成。
- 清空文件列表只删除浏览器中的打开记录，不删除电脑中的原文件。
- 本次更新没有新增浏览器权限，也没有改变云端分享默认关闭的状态。
- 只有主动上传或在线分享时，内容才会发送到用户选择的存储服务。
- 不包含 Workbench 自有账号、广告、遥测、内置存储地址或预置密钥。

## 已知限制

- Chrome 和 Edge 当前仍需手动加载预览版，正式面向普通用户的商店版本尚未上线。
- Safari 只能生成扩展资源，仍需完成 macOS/Xcode 包装、签名和真机验证，因此本次没有 Safari 安装包。
- 本地相对图片解析、提示框完整样式、脚注、图片灯箱和外部文件变化检测尚未全部迁移，逐项状态见[功能迁移矩阵](feature-migration.md)。
- 阿里云 OSS 和单位提供的上传连接属于可选功能，仍需用户提供自己的有效配置。
